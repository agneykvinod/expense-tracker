# FINVERO — PROJECT CONTEXT

## Project
Finvero is a personal credit-card intelligence and financial-management
platform.

## Current stage
Prototype / development version.

## Goal
Build a production-quality fintech platform that helps users:
- manage credit cards
- understand spending
- compare cards
- receive card recommendations
- track expenses
- eventually connect financial accounts
- eventually provide financial products through regulated partners

## IMPORTANT
This is an existing project.

Do NOT:
- rewrite the entire application unnecessarily
- replace working code without reason
- remove existing functionality
- create duplicate navigation systems
- change the architecture without explaining why

Before modifying code:
1. Inspect the relevant files.
2. Understand how the existing implementation works.
3. Identify exactly where the change should be made.
4. Make the smallest safe change.
5. Preserve existing functionality.
